# Daily Report（日報アプリ）技術仕様

## 概要
コンサルティング会社向けの日報管理ツール。毎日の業務記録と、週次AI振り返り機能を提供。

## ファイル
- `daily-report.html` — 単一HTML（AI News とは独立）

## 機能一覧

### 日次記録
- **業務内容**: 今日取り組んだタスクを記録
- **課題・困ったこと**: 業務で感じた壁や問題点
- **気づき・学び**: その日のインサイト
- **明日への意気込み**: 翌日のアクション・モチベーション

### 継続支援
- 🔥 連続記録日数（ストリーク）をヘッダーに常時表示
- 3秒間の無操作で自動保存（入力途中でも安心）
- 日付ナビゲーション（◀ 今日 ▶）で素早く移動

### 週次AIレビュー（OpenAI API）
- 1週間分の日報を集約し、AIが自動分析
- 生成内容:
  - 今週のサマリー
  - 課題の深掘り分析
  - 気づきの整理・強化
  - おすすめの本（2〜3冊）
  - 思考の整え方（フレームワーク提案）
  - 来週やるべきステップ（優先度付き）
- モデル: `gpt-4o-mini`

### データ管理
- localStorage で保存（サーバー不要）
- JSON エクスポート / インポート対応
- 全データ削除（二重確認付き）

## 技術構成
- 単一HTML + CSS + JavaScript（外部依存なし）
- レスポンシブ対応（モバイル可）
- APIキーはlocalStorageに保存（サーバー送信なし）
