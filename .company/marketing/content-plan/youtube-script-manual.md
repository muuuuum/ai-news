# YouTube AI News 台本制作マニュアル

> AI News Daily の YouTube 台本を書く際のルール・品質基準・禁止事項をまとめたもの。
> content-engine (ECC) + AI News Daily ブランドガイドラインから導出。

---

## 1. ブランドボイス

### AI News Daily のトーン
| 要素 | 方向性 |
|------|--------|
| 印象 | 知的・信頼性・先進的 |
| 話し方 | プロフェッショナルだが親しみやすい |
| 差別化 | データと出典に基づく信頼性 × 分かりやすさ |
| ベンチマーク | Reuters の信頼感 + ledge.ai の親しみやすさ |

### 口調ルール
- **です・ます調** を基本とする
- 専門用語は初出時に一言で説明を添える
- 数字と固有名詞を多用する（具体性が信頼を生む）
- 感嘆や驚きは控えめに。事実で驚かせる

### 良い例 / 悪い例

| 悪い例 | 良い例 |
|--------|--------|
| 「すごいニュースが飛び込んできました！」 | 「OpenAIが GPT-5.4 を発表しました。」 |
| 「AIの進化が止まりません」 | 「Claude 4.6 の推論速度は前世代比2.3倍です」 |
| 「これは革命的な発表です」 | 「この発表で影響を受ける企業は推定1,200社です」 |
| 「ヤバい時代になりました」 | 「昨年同期比で AI スタートアップの資金調達額が47%増加しています」 |

## 2. 台本構成の原則

### WHAT → WHY → SO WHAT

すべてのニュースセグメントはこの3層で構成する。

1. **WHAT（事実）**: 何が起きたか。数字・固有名詞で具体的に
2. **WHY（背景）**: なぜそれが重要か。業界文脈・比較データで補強
3. **SO WHAT（影響）**: 視聴者にとっての意味。次に何が起きるか

### 冒頭は「結果」で始める

content-engine の YouTube ルール:
- **結果やテンション（問い）を冒頭に置く**
- 自己紹介、挨拶、前置きは後回し
- 最初の5秒で「この動画を見る理由」を提示する

### 論理展開で構成する

- フィラーセクション（「さて」「ところで」で繋ぐだけの区間）は禁止
- すべてのセクションが情報を前に進める
- チャプタリングは明確さに貢献する場合のみ使う

## 3. 禁止表現リスト

### 絶対禁止（発見したら即書き直し）

| 禁止表現 | 理由 |
|---------|------|
| 「急速に進化する〇〇の世界で」 | 汎用フレーズ。何も言っていない |
| 「革命的」「ゲームチェンジャー」 | ハイプ。事実で示す |
| 「最先端の」「画期的な」 | 形容詞で飾らない。具体的な性能差を示す |
| 「ヤバい」「すごすぎる」 | 感想ではなく事実を伝える |
| 「AIの進化が止まりません」 | クリシェ。何がどう変わったかを言う |
| 「皆さんはどう思いますか？」（本編中） | エンゲージメントベイト。CTA区間でのみ許可 |
| 「〇〇と言われています」（出典なし） | 誰が言ったか明示する |
| 「簡単に言うと」の多用 | 最初から簡潔に書く |

### 注意表現（文脈次第）

| 表現 | 許可条件 |
|------|---------|
| 「注目の」 | 具体的な注目理由（数字・事実）が直後にある場合 |
| 「重要な」 | 何がどう重要かの説明が続く場合 |
| 「大きな影響」 | 影響の具体的な内容・規模が示される場合 |

## 4. ニュース選定基準

### 優先度マトリクス

| 高優先 | 中優先 | 低優先 |
|--------|--------|--------|
| 主要企業の新モデル発表 | 資金調達ニュース | 人事異動 |
| 重大なセキュリティ事件 | 新サービスローンチ | カンファレンス予告 |
| 規制・法制度の変更 | ベンチマーク結果 | 業界レポート |
| ベンチマークで大差がついた比較 | パートナーシップ | アンケート調査 |
| オープンソースの画期的リリース | 研究論文の成果 | 噂・リーク |

### 選定ルール
1. **1本の動画にニュースは3-5件**（Daily の場合）
2. **カテゴリの偏りを避ける**: モデル2件+ビジネス1件+セキュリティ1件 のように混ぜる
3. **トップニュースは最もインパクトが大きいもの**: HOOKで使う
4. **ソースは2つ以上**: 1次ソース + 報道を突き合わせる

## 5. 映像演出ガイド

### 画面構成パターン

| パターン | 使用場面 | 内容 |
|---------|---------|------|
| ニュースカード | ニュース紹介時 | AI News Daily のカードデザインを踏襲 |
| データテーブル | 比較・ベンチマーク | サイトの比較テーブルスタイルを流用 |
| 棒グラフ | 数値比較 | AI News Daily のチャートスタイル |
| タイムライン | 経緯説明 | 左ボーダー + ドットのタイムライン |
| スクリーンショット | 公式発表・ツイート | 出典元の画面キャプチャ |
| 図解 | 技術解説 | AI News Daily のインフォグラフィックスタイル |

### テロップルール
- **キーワード強調**: ニュースの核心を短く（10文字以内）
- **数字テロップ**: 重要な数値は大きく表示
- **出典テロップ**: 画面右下に出典名を常時表示
- **フォント**: Noto Sans JP（サイトと統一）

### カラーシステム（サイト準拠）
| カテゴリ | カラー |
|---------|--------|
| モデル・研究 | 紫 (#7c3aed) |
| ビジネス | 青 (#2563eb) |
| エージェントAI | 緑 (#059669) |
| セキュリティ | 赤 (#dc2626) |
| スタートアップ | ティール (#0d9488) |

## 6. 品質ゲート（公開前チェック）

### 必須チェック（全項目クリアで公開可）

**内容**
- [ ] すべてのニュースに1次ソースのURLがある
- [ ] 数値データに出典がある
- [ ] 禁止表現が含まれていない
- [ ] WHAT → WHY → SO WHAT の3層構成になっている
- [ ] 冒頭HOOKが具体的な事実・数字で始まっている

**構成**
- [ ] 想定尺に対して文字量が適切（1分≒300文字目安）
- [ ] 各セクションが情報を前に進めている（フィラーなし）
- [ ] チャプター（タイムスタンプ）が設定されている

**ブランド**
- [ ] AI News Daily のトーンと一致している
- [ ] 映像演出がカラーシステムに準拠している
- [ ] CTAが自然で、エンゲージメントベイトになっていない

**技術**
- [ ] TTS で読み上げた際に不自然な箇所がない
- [ ] 英語の固有名詞に読み方ガイドがある
- [ ] 略語は初出時にフルネームを併記している

## 7. AI台本生成プロンプト設計

### Sequential Pipeline での使用

```bash
# Step 1: ニュース選定
claude -p "ai-news/index.html を読み、本日のトップニュース3件を選定してください。
選定基準: youtube-script-manual.md の「ニュース選定基準」に従う。
出力: ニュースタイトル、カテゴリ、重要度、ソースURL"

# Step 2: 台本生成
claude -p "選定した3件のニュースから YouTube 台本を生成してください。
テンプレート: youtube-script-template.md
ルール: youtube-script-manual.md
フォーマット: daily（8-12分）"

# Step 3: 品質チェック（De-Sloppify）
claude -p "生成した台本を youtube-script-manual.md の品質ゲートでチェックしてください。
禁止表現を削除し、具体的な数字・事実に置き換えてください。
ソースの確認も行ってください。"
```

### プロンプトキャッシュ対象
以下は毎回同じ内容のため、cache_control で固定:
- youtube-script-template.md（テンプレート全文）
- youtube-script-manual.md（マニュアル全文）
- AI News Daily のブランドボイス定義

## 8. リパーポージングルール

### Web → YouTube
1. AI News Daily サイトからトップニュースを抽出
2. ヒーロー記事 → 動画の HOOK + ニュース1
3. カード記事 → ニュース2-5
4. サイドバーの数字 → データテロップに活用
5. ソースボックス → 概要欄のリンク集

### YouTube → Web
1. 動画の文字起こしをサイト記事に変換
2. 動画リンクをサイトに埋め込み（相互送客）
3. 動画で作ったグラフィックをサイト記事にも使用
