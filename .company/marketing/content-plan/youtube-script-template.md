## 1. HOOK — 冒頭つかみ（0:00〜0:30）

> **目的**: 視聴維持率の最重要区間。「結果」「衝撃」「問い」のいずれかで始める。
> **絶対ルール**: 自己紹介や挨拶から始めない。事実から始める。

```
[画面: {{メインビジュアル / データ / スクリーンショット}}]

{{ここに冒頭の1文。最も衝撃的な事実・数字・結果を置く}}

{{2文目。なぜそれが重要かを1文で}}

{{3文目。「今日は〜をお伝えします」の予告。具体的に}}
```

**チェック**:
- [ ] 最初の1文に具体的な数字・事実・結果がある
- [ ] 「今日のAIニュースをお届けします」のような汎用フレーズではない
- [ ] 15秒以内に視聴者が「続きを見たい」と思える

## フォーマット別ガイド

### Daily（毎日配信）
- **尺**: 8-12分
- **ニュース数**: 3-5件
- **構成**: HOOK → OP → ニュース×3-5 → WRAP → CTA
- **トーン**: テンポよく、簡潔に

### Weekly（週まとめ）
- **尺**: 15-20分
- **ニュース数**: 5-8件（週のハイライト）
- **構成**: HOOK → OP → ランキング形式 → 来週の注目 → CTA
- **トーン**: 振り返り＋展望

### Deep Dive（深掘り）
- **尺**: 15-25分
- **テーマ数**: 1件を徹底解説
- **構成**: HOOK → OP → 背景 → 技術解説 → 影響分析 → 未来予測 → CTA
- **トーン**: 教育的、丁寧な説明

### Breaking（速報）
- **尺**: 3-5分
- **ニュース数**: 1件
- **構成**: HOOK（即事実） → 詳細 → 影響 → CTA
- **トーン**: 緊迫感、スピード重視
