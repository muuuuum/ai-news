# パラノイア式ニュース解説スタイルガイド

> 参考: Paranoia_パラノイア【有益】(@paranoia369)
> 「ようこそ。本質領域へ。」

## コアコンセプト

**ニュースの事実を伝えるだけでは価値がない。
「それがあなたの現実にどう反映されるか」まで落とし込んで初めて有益になる。**

## パラノイアさんの手法分析

### 1. タイトル構造
```
【核心概念】衝撃的な問い or 数字｜出典
```
例:
- 【富の階段②】積み立て投資ではお金持ちになれない。資産１億にするために必要なこととは？
- 【実践済み】海外で88億回再生された話題のプログラム「ウィンターアーク」とは？
- 【１週間で1.7億回見られた投稿】痛みを伴うが、１日で人生を再構築する「アンチビジョン」とは？

**ポイント:**
- 【】で核心を括る
- 具体的な数字（82.5%、88億回、1.7億回）
- 「なぜ〜なのか？」「〜とは？」の問いかけ
- 海外の権威ある出典を添える

### 2. 動画構成（チャプター方式）
```
0:00  核心の問い（なぜ多くの人は間違えるのか？）
5:00  フレームワークの提示（○○の法則）
15:00  具体的なステップ（3つの戦略）
25:00  日本での応用方法
35:00  まとめ + 行動喚起
```

**ポイント:**
- 「なぜ」から始まり「どうする」で終わる
- 抽象→具体→行動の流れ
- 段階構造（レベル1→2→3→4）

### 3. 語り口の特徴
- **断定的**: 「〜です」ではなく「〜だ」
- **問いかけ**: 視聴者に考えさせる
- **対比**: 「凡人の特徴 vs 成功者の特徴」
- **具体例**: 必ず数字と実例を添える
- **権威付け**: 「20ヵ国で翻訳」「10億稼ぐ男」

## AI News Dailyへの適用

### ニュース記事の「パラノイア式」変換

**通常のニュース報道:**
> GoogleがAnthropicに約6兆円を投資する計画。AI企業間の計算能力確保競争が激化。

**パラノイア式変換:**
> 【AI戦争の本質】なぜGoogleは6兆円をAnthropicに投じるのか？
> これは単なる投資ニュースじゃない。
>
> 「計算資源を持つ者がAIを制する」—— この法則を理解していない人は、
> 3年後に「なぜこうなった？」と言うことになる。
>
> あなたがエンジニアなら、今すぐAnthropicのAPIに触れておくべきだ。
> あなたが投資家なら、クラウドインフラ銘柄を見直すタイミングだ。
> あなたが経営者なら、AI計算コストの見積もりを3倍にしろ。

### テンプレート: 各ニュースの構造

```
1. 【フック】衝撃の事実 or 数字（5秒）
   → 「6兆円。この数字の意味が分かるか？」

2. 【事実】何が起きたか（15秒）
   → GoogleがAnthropicに投資する。その規模は約6兆円。

3. 【本質】なぜそれが重要か（30秒）
   → 計算資源の確保 = AIの覇権。
   → これは技術の話じゃない、地政学の話だ。

4. 【あなたへの影響】現実にどう反映されるか（30秒）
   → エンジニアなら → ○○
   → 投資家なら → ○○
   → 一般人なら → ○○

5. 【締め】一言で要約（5秒）
   → 「覚えておいて。計算資源を制する者がAIを制する。」
```

### ミライちゃんの口調への変換

パラノイアさん:
> 「なぜ多くの人間が"普通"で終わるのか？」

ミライちゃん:
> 「人間さん、なぜみんな同じところで止まるか知ってる？
>  ボクの時代だと答え出てるんだけど、聞きたい？」

**ルール:**
- パラノイアの「断定」→ ミライの「未来からの助言」に変換
- パラノイアの「権威」→ ミライの「2089年の知識」に変換
- パラノイアの「数字」→ そのまま活用（数字は普遍的に強い）
- パラノイアの「あなたへの影響」→ ミライの「人間さんにとってはこういうこと」に変換

## 台本品質チェック

各ニュースの台本で以下を確認:
- [ ] 「あなたへの影響」パートがあるか
- [ ] 具体的な数字が2つ以上入っているか
- [ ] 「なぜ重要か」が業界論ではなく個人レベルで語られているか
- [ ] 問いかけが1つ以上あるか
- [ ] 行動喚起（〜すべきだ、〜を見直せ）があるか
