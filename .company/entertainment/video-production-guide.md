# 動画制作ガイド v2 — パラノイア式エンタメ × VTuber

## 動画の構成原則

### パラノイア式5段構造

1本のニュース（60秒）で使う構造:

```
[HOOK] 5秒 — 衝撃の数字 or 問い
   → clip_surprised / clip_serious
   → テロップ: 大文字で核心を叩く

[FACT] 10秒 — 何が起きたか（事実のみ）
   → clip_talking + 記事動画PIP
   → テロップ: ニュース枠で事実表示

[DEPTH] 15秒 — なぜ重大か（3段深掘り）
   → 記事動画を全画面 + clip_serious右下
   → テロップ: 段階的に深掘り内容が出現
   → 途中でシーン切替（異なるVeo動画に）

[YOUR LIFE] 20秒 — あなたの人生にどう影響するか
   → 記事動画全画面 + clip_pointing右下
   → テロップ: 「💡 あなたへの影響」枠
   → ここが最も重要。個人レベルに落とし込む

[CLOSE] 10秒 — 問いかけで締める
   → clip_talking → clip_waving
   → テロップ: キーナンバー + 締めの一言
```

### クリップ使い分けルール

| シーン | キャラクリップ | 用途 |
|--------|-------------|------|
| OP挨拶 | clip_talking | 通常の入り |
| 衝撃ニュース | clip_surprised | 「えっ」リアクション |
| 重要ポイント | clip_serious | 「これ大事」 |
| 解説中 | clip_talking | 通常解説 |
| 画面の図解を指す | clip_pointing | 「ここ見て」 |
| 面白いニュース | clip_laugh | ユーモア |
| エンディング | clip_waving | 「またね」 |
| カジュアルシーン | clip_laugh | 親しみ |

### 記事動画（Veo）のルール

- **同じ8秒動画をループしない**
- ニュース1本につき最低**3つの異なるシーン動画**を用意
- 各シーンは記事の内容に直結する映像:
  - FACT用: 事実を表す映像（企業、技術、製品）
  - DEPTH用: 影響を表す映像（人々、社会、未来）
  - YOUR LIFE用: 個人への影響を表す映像（生活、仕事）

### テロップのルール

- ニュース枠（四角い枠、ヘッダーバー付き）
- 金額は**円表記メイン**（ドル併記OK）
- 「あなたへの影響」は緑の枠で差別化
- フォント: Noto Sans JP Bold/Black
- キーワードはカテゴリカラーで色付け

## キャラクター設定（v2）

### 名前・口調は今後確定
- 現在は名前未定（「ミライ」から変更予定）
- 口調・一人称も再設定予定

### ビジュアル仕様（確定）
- 2.5次元スタイル（リアルな質感 + アニメ比率）
- 黒髪、サイドテール
- グリーングレーの瞳
- ネイビーブレザー + 水色トリム + 白シャツ
- 青いスタッドピアス
- 表情豊か（6パターンの動画クリップ）

## 品質チェックリスト

動画完成時に確認:
- [ ] 同じ動画クリップをループしていないか
- [ ] パラノイア式5段構造になっているか
- [ ] 「あなたへの影響」パートがあるか
- [ ] 具体的な数字が2つ以上入っているか
- [ ] 問いかけが1つ以上あるか
- [ ] テロップのブレ・ラグがないか
- [ ] 音声と映像が同期しているか
- [ ] 円表記になっているか
