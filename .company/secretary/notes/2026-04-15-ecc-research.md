## YouTube AI News PJ に直接活用できるスキル

### 1. content-engine（コンテンツエンジン）⭐最重要
- **用途**: X, LinkedIn, TikTok, YouTube, ニュースレター向けのコンテンツ制作システム
- **YouTube向けルール**:
  - 結果やテンション（問い）を早く見せる
  - 論理展開で構成する（フィラーセクションNG）
  - チャプタリングは明確さに貢献する場合のみ
- **リパーポージングフロー**: アンカー素材→3-7個のアトミッククレーム抽出→鮮明さ・新規性でランク→プラットフォーム別適応
- **品質ゲート**: ハイプ言語禁止、エンゲージメントベイト禁止、具体的主張必須
- **禁止表現**: "In today's rapidly evolving landscape", "game-changer", "revolutionary" 等

### 2. article-writing（記事ライティング）
- **用途**: 台本のベース記事・ブログ投稿の作成
- **核心ルール**: 具体的なモノ（例、数字、コード、スクショ）で始める → 説明はその後
- **ライティングプロセス**: 聴衆・目的を明確化 → ハードアウトライン → 証拠から始める → テンプレ臭を排除
- **voice handling**: brand-voice スキルとの連携でトーン統一

### 3. market-research（マーケットリサーチ）
- **用途**: 競合YouTubeチャンネル調査、ターゲット分析
- **リサーチモード**: 競合分析、マーケットサイジング、テクノロジーリサーチ
- **出力形式**: エグゼクティブサマリー → 主要発見 → 示唆 → リスク → 推奨 → ソース
- **品質**: 全数値にソース必須、古いデータにフラグ、反証も含める

### 4. videodb（動画DB）⭐重要
- **用途**: 動画の取り込み・理解・編集・アセット生成
- **3機能**: See（取り込み）→ Understand（インデックス・検索）→ Act（編集・変換）
- **編集機能**: 字幕、テキスト/画像オーバーレイ、ブランディング、音声オーバーレイ、吹替、翻訳
- **重要**: ffmpeg/moviepy ではなく VideoDB のサーバーサイド処理を推奨

### 5. cost-aware-llm-pipeline（コスト最適化パイプライン）
- **用途**: AI台本生成のコスト管理
- **モデルルーティング**: タスク複雑度でHaiku/Sonnet/Opus を自動選択
- **予算管理**: イミュータブルなコストトラッカー、予算上限設定
- **プロンプトキャッシュ**: 繰り返しシステムプロンプトのキャッシュで30-90%コスト削減
- **価格参考**: Haiku $0.80/1M入力 vs Sonnet $3.00 vs Opus $15.00

## 活用できるエージェント

### chief-of-staff（チーフオブスタッフ）
- マルチチャネルメッセージの4段階分類トリアージ
- 関係性コンテキストを使った返信ドラフト生成
- **応用**: YouTube コメント管理、SNS 対応の自動化に転用可能

### planner（プランナー）
- 複雑な機能の実装計画を4フェーズで作成
- 要件分析 → アーキテクチャレビュー → ステップ分解 → 実装順序
- **応用**: YouTube パイプラインの各フェーズの詳細計画に活用

### loop-operator（ループオペレーター）
- 自律ループの安全な運用・監視・介入
- 停止条件、進捗チェックポイント、コスト逸脱検知
- **応用**: 定期的な動画生成パイプラインの自動運用

## 活用できるループパターン（autonomous-loops）

### Sequential Pipeline（逐次パイプライン）⭐即導入可能
```bash
# YouTube動画制作パイプライン例
claude -p "ai-newsの最新ニュースを読み、トップ3を選定"
claude -p "選定したニュースから台本を生成（フック→本編→CTA）"
claude -p "台本をレビューし品質ゲートを通す"
```

### De-Sloppify Pattern（品質クリーンアップ）
- 実装ステップの後に専用のクリーンアップパスを追加
- 「やるな」の指示ではなく、別のパスで不要物を除去
- **応用**: 台本生成後の品質チェック（ハイプ言語除去等）

### Continuous Claude PR Loop
- PRの自動作成 → CI待ち → 自動マージのループ
- `SHARED_TASK_NOTES.md` でイテレーション間のコンテキスト共有
- **応用**: 日次の動画制作を自動化する際の基盤パターン

### Infinite Agentic Loop
- 仕様ベースの並列サブエージェント生成
- 各エージェントに異なるクリエイティブ方向性を割り当て
- **応用**: サムネイルバリエーション生成、台本の角度違い生成

## PJへの導入ロードマップ

### Phase 1（即導入）
1. **content-engine** の YouTube ルールを台本テンプレートに組み込む
2. **market-research** パターンで競合調査を実施
3. **Sequential Pipeline** でニュース選定→台本生成→レビューの3ステップ自動化

### Phase 2（パイプライン構築時）
4. **videodb** で動画編集の自動化基盤を構築
5. **cost-aware-llm-pipeline** でAPI コスト管理を導入
6. **brand-voice** でAI News Daily のトーン統一

### Phase 3（運用最適化時）
7. **continuous-learning** で制作ノウハウを自動蓄積
8. **loop-operator** + **Continuous Claude Loop** で日次制作を自動化
9. **De-Sloppify** パターンで品質の自動クリーンアップ
