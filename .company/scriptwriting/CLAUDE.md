# 台本制作部門（スクリプトライティング）

## ミッション
YouTube AI News動画の台本を制作する専門部署。
マーケティング・エンタメ・クリエイティブの3部署のルールを統合し、最高品質の台本を書く。

## 参照すべきドキュメント（必ず読むこと）

### マーケティング部門から
- `marketing/content-plan/youtube-script-template.md` — 台本テンプレート（HOOK→OP→MAIN→WRAP→CTA構成）
- `marketing/content-plan/youtube-script-manual.md` — 品質基準・禁止表現・ブランドボイス

### エンタメ部門から
- `entertainment/paranoia-style-guide.md` — パラノイア式5段構造（HOOK→FACT→DEPTH→YOUR LIFE→CLOSE）
- `entertainment/video-production-guide.md` — 動画制作ガイド・クリップ使い分け

### クリエイティブ部門から
- キャラクター設定 v2（`creative/briefs/character-v2.md`）— 口調・やること・やらないこと

## 台本制作フロー

1. ニュースデータを読む（data/reports.json から最新日付のトップ記事）
2. マーケティングの品質基準を確認（禁止表現リスト、ブランドボイス）
3. エンタメのパラノイア式5段構造で台本を構成
4. キャラクター設定v2の口調を適用（設定語りは入れない）
5. 品質チェックリストを全項目通す
6. 身振り手振り指定を付ける（video-production-guide.mdのクリップ使い分けルール）

## 品質チェックリスト（全項目必須）

### マーケティング基準
- [ ] 最初の1文に具体的な数字・事実がある
- [ ] 「今日のAIニュースをお届けします」のような汎用フレーズではない
- [ ] 禁止表現が含まれていない（「革命的」「ゲームチェンジャー」「ヤバい」等）
- [ ] WHAT → WHY → SO WHAT の3層構成になっている
- [ ] すべてのニュースにソースがある
- [ ] 想定尺に対して文字量が適切（1分≒250〜300文字）

### エンタメ基準（パラノイア式）
- [ ] 「あなたへの影響」パートがある
- [ ] 具体的な数字が2つ以上入っている
- [ ] 「なぜ重要か」が業界論ではなく個人レベルで語られている
- [ ] 問いかけが1つ以上ある
- [ ] 行動喚起がある

### クリエイティブ基準
- [ ] キャラクターの口調が一貫している
- [ ] 禁忌に触れていない（攻撃的表現、政治的偏り、過剰リアクション等）
- [ ] 通貨は円表記メイン
