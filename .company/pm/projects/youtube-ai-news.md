# プロジェクト: YouTube AI News チャンネル

## 概要
AI News Daily で収集・整理している最新AIニュースを、YouTube動画として配信するパイプラインを構築する。
ニュース収集 → 台本作成 → デザイン → 編集 → 投稿 の全工程を体系化し、継続運用できるシステムにする。

## ゴール
1. AIニュースのYouTube動画を定期的に投稿できるワークフローを確立する
2. 台本テンプレート・デザインガイドライン・編集フローを標準化する
3. 可能な限り自動化し、1本あたりの制作コストを最小化する

## 制作ワークフロー（目標フロー）

```
1. ニュース収集（自動）
   └── ai-news/scripts/ の既存収集システム
   └── AI News Daily サイトのコンテンツ

2. 台本作成（ディレクター）
   ├── ニュースの選定・優先順位付け
   ├── 台本テンプレートに流し込み
   ├── フック・本編・CTAの構成
   └── 出力: marketing/content-plan/youtube-*.md

3. デザイン
   ├── サムネイル生成
   ├── テロップ・グラフィック素材準備
   └── 出力: creative/assets/

4. 制作・編集
   ├── 音声生成（TTS or AI音声）
   ├── 映像素材の組み立て
   ├── テロップ・エフェクト挿入
   ├── BGM・SE追加
   └── 出力: 完成動画ファイル

5. 投稿
   ├── メタデータ生成（タイトル・説明・タグ）
   ├── サムネイル設定
   ├── YouTube アップロード
   └── SNS告知（将来）
```

## 技術スタック候補

| 工程 | 候補ツール | 備考 |
|------|-----------|------|
| 台本生成 | Claude API / GPT-4 | プロンプトテンプレートで品質安定化 |
| 音声生成 | VOICEVOX / ElevenLabs / Google TTS | 日本語対応必須 |
| 動画編集 | FFmpeg / Remotion / Revideo | プログラマティック編集が理想 |
| サムネイル | Figma API / Canvas API / AI生成 | テンプレートベース |
| 投稿 | YouTube Data API v3 | OAuth2認証 |
| 字幕 | Whisper / YouTube自動字幕 | 精度と速度のバランス |
| スケジューリング | GitHub Actions / Cron | 定期実行 |

## メモ
- AI News Daily のWebサイトと YouTube は相互送客の関係にする
- 初期は週1本ペースで品質を安定させ、徐々に頻度を上げる
- 完全自動化より「半自動 + 人間レビュー」から始めるのが現実的
