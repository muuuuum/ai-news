# YouTube サムネイルデザインテンプレート

> AI News Daily のブランドガイドラインに準拠した YouTube サムネイル制作マニュアル。
> CTR 最適化とモバイル視認性を重視した設計。

---

## 1. 基本仕様

| 項目 | 値 |
|------|-----|
| サイズ | 1280 × 720 px |
| アスペクト比 | 16:9 |
| ファイル形式 | PNG（透過不要）/ JPG |
| ファイルサイズ | 2MB 以下 |
| カラースペース | sRGB |

### セーフゾーン

```
┌─────────────────────────────────────────┐
│ ┌─ 上マージン 40px ──────────────────┐  │
│ │                                    │  │
│ │                                    │  │
│ │         SAFE ZONE                  │  │
│ │       (1200 × 640)                 │  │
│ │                                    │  │
│ │                                    │  │
│ └────────────────────────────────────┘  │
│           下マージン 40px               │
│  左40px                        右40px   │
│                        ┌──────────┐     │
│                        │ 時間表示 │     │
│                        │ 回避域   │     │
│                        └──────────┘     │
└─────────────────────────────────────────┘
```

**重要**: 右下 160×40px は YouTube の再生時間表示と重なるため、テキストを置かない。

| 用途 | カラー | 備考 |

## 4. タイポグラフィ

### フォント

| 用途 | フォント | ウェイト | サイズ |
|------|---------|---------|--------|
| メインテキスト（日本語） | Noto Sans JP | 900 (Black) | 48-56px |
| メインテキスト（英数字） | Inter | 900 (Black) | 48-56px |
| サブテキスト | Noto Sans JP | 700 (Bold) | 24-28px |
| 数字ハイライト | Inter | 900 (Black) | 36-44px |
| カテゴリバッジ | Inter / Noto Sans JP | 800 (ExtraBold) | 14-16px |
| 日付 | Inter | 600 (SemiBold) | 16px |
| BREAKING | Inter | 900 (Black) | 20px, letter-spacing 0.15em |

### テキストルール

1. **最大2行**: メインテキストは2行以内。3行は禁止
2. **1行15文字以内**: 日本語は1行あたり最大15文字
3. **数字は大きく**: 金額・件数・パーセントは周囲より20%以上大きく
4. **テキスト影**: `2px 2px 8px rgba(0,0,0,0.7)` で暗い背景でも視認性確保
5. **行間**: 1.2（タイトなレイアウト）

## 5. ロゴ配置

### AI News Daily ロゴ

```
┌────────────┐
│ AI  News   │
│     Daily  │
└────────────┘
```

| 要素 | 仕様 |
|------|------|
| 「AI」マーク | 赤背景 (#dc2626) + 白文字、24×24px、角丸4px |
| 「News」 | 白文字、18px、weight 900 |
| 「Daily」 | 赤文字 (#dc2626)、18px、weight 900 |
| 配置 | 左上（上40px, 左40px） |
| 背景 | 半透明黒パネル `rgba(0,0,0,0.3)` + blur(4px) |

ロゴは**全パターン共通**で左上に配置。小さめだがブランド認識の一貫性を保つ。

## 6. モバイル視認性チェック

YouTube 視聴の **70%以上がモバイル**。サムネイルはスマホ画面で約 168×94px に縮小表示される。

### モバイルチェックリスト

- [ ] メインテキストを **50%に縮小** しても読めるか
- [ ] 色のコントラスト比が **4.5:1 以上** あるか（白文字 on ダーク背景は通常OK）
- [ ] 要素が3つ以内に収まっているか（テキスト + 数字 + ロゴ）
- [ ] 右下の再生時間表示域にテキストが被っていないか
- [ ] 背景グラデーションが単調すぎず、テキストを引き立てているか

### 50%縮小テスト

Figma/Canva で 640×360px に縮小表示し、以下を確認:
1. メインテキストが一目で読める
2. 数字ハイライトが識別できる
3. カテゴリカラーが判別できる

## 7. 禁止事項

### 絶対禁止

| 禁止事項 | 理由 |
|---------|------|
| 赤い矢印 + 驚き顔 | クリックベイト感が強く、ブランド毀損 |
| 文字だけで背景なし | 素人感。プロフェッショナルさが失われる |
| 4行以上のテキスト | モバイルで読めない |
| 蛍光色の多用 | 安っぽくなる。ブランドカラー外は使わない |
| 人物の顔写真（許諾なし） | 肖像権リスク |
| 他社ロゴの大きな使用 | 商標リスク。言及程度の小サイズはOK |
| 白背景 | YouTube の白UIに溶け込んで目立たない |
| テキストのみ（ビジュアルなし） | クリック率が低い |

### 注意事項

| 注意事項 | 許可条件 |
|---------|---------|
| 「!」「!?」の多用 | 1個まで。速報時のみ |
| 英語テキスト | メインが日本語ならサブに英語OK |
| グラデーション以外の背景 | ブランドカラー範囲内であれば可 |

## 8. 制作ツール・再現手順

### Figma での制作

1. **フレーム作成**: 1280×720px
2. **背景**: Rectangle → Fill を Linear Gradient に設定、カテゴリ別カラーを適用
3. **ロゴ配置**: コンポーネント化して左上に固定
4. **テキスト**: Noto Sans JP Black / Inter Black を使用
5. **テキスト影**: Effects → Drop Shadow (X:2, Y:2, Blur:8, Color:#000 70%)
6. **数字ハイライト**: 別テキストレイヤー、カテゴリの明るい色を適用
7. **バッジ**: Auto Layout の Rectangle + Text
8. **書き出し**: PNG 2x（2560×1440 → YouTube 推奨解像度）

### Canva での制作

1. **カスタムサイズ**: 1280×720px で新規作成
2. **背景**: 「グラデーション」で検索 → カスタム色で調整
3. **テキスト**: 「Noto Sans JP」で検索 → Black ウェイト
4. **要素**: 図形で角丸四角を作りバッジに
5. **ダウンロード**: PNG 形式

### テンプレート化のコツ

- Figma: ページごとにパターン A/B/C/D を作り、Variables でカラーを切り替え
- Canva: ブランドキットにカラーとフォントを登録、テンプレートとして保存
