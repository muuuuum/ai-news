# AI News Daily デザインマニュアル

> **参考サイト**: [ledge.ai](https://ledge.ai)
> **コンセプト**: モダン × ミニマル × プロフェッショナル — 信頼性の高いAIテックメディア
> **参考通信社**: Reuters, AP通信, AFP通信

---

## 1. ブランドアイデンティティ

### 1.1 サイト名称
- **正式名称**: AI News Daily
- **ロゴ表記**: `AI` (マーク) + `News` (黒) + `Daily` (アクセント赤)
- **タグライン**: 世界のAIニュースを毎朝お届け

### 1.2 ブランドトーン
| 要素 | 方向性 |
|------|--------|
| 印象 | 知的・信頼性・先進的 |
| トーン | プロフェッショナルだが親しみやすい |
| 差別化 | データ可視化と速報性を両立する日本語AIメディア |
| ベンチマーク | ledge.ai の白基調ミニマルレイアウト + Reuters の信頼感 |

### 1.3 ターゲットユーザー
- AI/テクノロジーに関心のあるビジネスパーソン
- AI開発者・エンジニア
- スタートアップ経営者・投資家
- 日本語圏のAI最新情報を求めるユーザー

## 2. カラーシステム

### 2.1 CSS変数定義

```css
:root {
  /* ── ベースカラー ── */
  --bg: #f4f5f7;            /* ページ背景: 薄いウォームグレー */

  --border: #e2e4e8;         /* ボーダー・区切り線 */

  /* ── テキストカラー ── */
  --text: #1a1a2e;           /* 見出し・主要テキスト */
  --text2: #3d3d5c;          /* 本文テキスト */

  --muted2: #9ca3af;         /* 最も薄いテキスト */

  /* ── アクセントカラー ── */
  --accent: #e63946;         /* プライマリ赤（ロゴ・速報・CTA） */
  --accent2: #457b9d;        /* セカンダリ青灰（未使用予備） */

  /* ── カテゴリカラー（濃/淡ペア） ── */
  --blue: #1d4ed8;           /* ビジネス */
  --blue-light: #eff6ff;
  --green: #059669;          /* エージェント */
  --green-light: #ecfdf5;
  --purple: #7c3aed;         /* モデル・研究 */

  --orange-light: #fffbeb;

}
```

### 2.2 カラー使用ルール

| 用途 | カラー | 備考 |
|------|--------|------|
| ページ背景 | `--bg` (#f4f5f7) | ledge.ai に倣い白系統を基調とする |

| カテゴリタグ | 各カテゴリの濃色/淡色ペア | 下記タグ仕様参照 |

## 3. タイポグラフィ

### 3.1 フォントスタック

```css
font-family: 'Noto Sans JP', 'Inter', -apple-system, BlinkMacSystemFont, sans-serif;
```

| 用途 | フォント | 理由 |
|------|---------|------|
| 日本語 | Noto Sans JP | Google Fonts。可読性が高く、ニュースサイトに最適 |
| 英数字 | Inter | 現代的でデータ表示に強い。数字の視認性が高い |
| フォールバック | system-ui | OS標準フォントで軽量化 |

### 3.2 ウェイト使い分け

| ウェイト | 用途 |
|---------|------|
| 400 (Regular) | 本文テキスト |
| 500 (Medium) | 日付、ソース名、補助ラベル |
| 700 (Bold) | セクション見出し、カード見出し、強調テキスト |
| 900 (Black) | ロゴ、セクションヘッダー、統計数値 |

### 3.3 フォントサイズ体系

| 要素 | サイズ | ウェイト | 行間 |

| カード説明文 | 12px | 400 | 1.7 |
| テーブルセル | 13px | 400 | - |

## 6. アイコン・ビジュアル方針

### 6.1 アイコン
- **方式**: 絵文字（Emoji）ベース
- **理由**: 外部ライブラリ不要、軽量、視認性が高い
- **使用例**: 🔥トップ, 🤖モデル, ⚙️エージェント, 📊統計, 🏆ランキング, 📅イベント, 🔒セキュリティ

### 6.2 サムネイル画像
- **方式**: CSSグラデーション + 絵文字オーバーレイ（画像ファイル不要）
- **サムネイル背景パターン**:
  - ダークネイビー: `linear-gradient(135deg, #1e1b4b, #312e81)` — Anthropic系
  - ディープブルー: `linear-gradient(135deg, #0c4a6e, #075985)` — OpenAI系
  - ミッドブルー: `linear-gradient(135deg, #1e3a5f, #1d4ed8)` — ビジネス系
  - ディープグリーン: `linear-gradient(135deg, #14532d, #166534)` — エージェント系
  - ダークレッド: `linear-gradient(135deg, #7f1d1d, #991b1b)` — セキュリティ系
- **アイコン**: opacity:0.18, 右下配置（48px カード / 80px ヒーロー）

### 6.3 ダイアグラム・インフォグラフィック
- **背景**: 淡いグラデーション（カテゴリカラーの淡色ベース）
- **ボックス**: 白背景 + カテゴリ色ボーダー2px + radius:8px
- **接続線**: カテゴリ色 + 矢印（⇄ 等）
- **タイムライン**: 左ボーダー2px + ドット12px丸 + position:relative

## 8. ページテンプレート構成

### 8.1 日次ニュースページの構成順序

1. **速報ティッカーバー** — 本日の重要ニュース3〜5件をスクロール表示
2. **ヘッダー** — ロゴ + 日付 + タグライン
3. **ナビゲーション** — カテゴリタブ（トップがデフォルトアクティブ）
4. **メインコンテンツ**:
   a. トップニュース（ヒーロー記事 1件）
   b. モデル・研究セクション（比較テーブル + カード2枚）
   c. エージェントAIセクション（図解 + カード2枚）
   d. ビジネスセクション（必要に応じて）
   e. 参考文献ソースボックス
5. **サイドバー**:
   a. 本日の注目数字（6件）
   b. 注目ランキング（5位まで）
   c. 今週のイベント（2〜4件）
6. **フッター** — ロゴ + 更新日時 + 自動更新情報

### 8.2 コンテンツ優先度

| 優先度 | コンテンツ | 配置 |
|--------|-----------|------|
| 最高 | トップニュース（ヒーロー） | メイン最上部 |
| 高 | カテゴリ別ニュース | メイン中部 |
| 高 | データ可視化（テーブル・チャート） | セクション内 |
| 中 | サイドバー統計 | 右カラム |
| 中 | ランキング | 右カラム |
| 低 | イベント情報 | 右カラム下部 |

## 9. ledge.ai デザイン準拠ポイント

現行デザインと ledge.ai を比較し、以下の方針を適用する:

| ledge.ai の特徴 | AI News Daily での適用 |
|-----------------|----------------------|
| 白基調のクリーンな背景 | `--bg: #f4f5f7` で実現済み |
| カード型レイアウト | ニュースカード・セクションボックスで統一 |
| 記事サムネイル + タイトル + 日付 | カードコンポーネントで実現 |
| カテゴリ色分け | タグシステムで5カテゴリ色分け |
| アクセスランキング | サイドバー「注目ランキング」で実現 |
| メルマガ登録バナー | 将来実装候補（収益化施策として検討） |
| 2カラムレイアウト | グリッド `1fr 300px` で実現 |
| シンプルなボーダー使い | `--border: #e2e4e8` + 薄い影で統一 |
| プロフェッショナルな印象 | フォント・色・余白の一貫性で担保 |

### 9.1 ledge.ai との差別化ポイント

| 差別化要素 | 説明 |
|-----------|------|
| 速報ティッカー | Reuters/AP 風の速報バーで通信社感を演出 |
| データ可視化 | ベンチマーク比較テーブル・収益チャート等をインライン配置 |
| インフォグラフィック | タイムライン・アーキテクチャ図をCSS純正で表現 |
| キーナンバーズ | 数字を大胆に見せて一目で分かるインパクト |
| カテゴリ速報タグ | グラデーションサムネイル + カテゴリタグでニュース性を強調 |

## 付録: デザインチェックリスト

新しいページ・コンポーネントを追加する際に確認:

- [ ] CSS変数を使用しているか（ハードコードしていないか）
- [ ] フォントウェイトは4段階（400/500/700/900）のいずれかか
- [ ] radius は 8px（カード）/ 3px（タグ）/ 2px（小要素）/ 20px（チップ）か
- [ ] 影は `0 1px 4px rgba(0,0,0,.06)` を基本としているか
- [ ] カテゴリ色は定義済みのペア（濃/淡）を使っているか
- [ ] レスポンシブ対応（860px / 540px）を考慮しているか
- [ ] ホバーインタラクションが定義されているか
- [ ] テキストの行間は 1.7 以上を確保しているか
